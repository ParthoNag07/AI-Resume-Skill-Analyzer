# ✦ AI Resume Skill Analyzer

A modern, responsive web application that analyzes a resume against required job skills and calculates a skill match score.

## 🚀 Live Demo

[View Live Project](https://parthonag07.github.io/AI-Resume-Skill-Analyzer/)

## 📌 About the Project

AI Resume Skill Analyzer is a frontend-based career tool designed to help job seekers quickly evaluate how well their resume matches a specific job's skill requirements.

Users can paste their resume, enter required job skills, and get an instant match score along with a list of matched skills.

## ✨ Features

* 📄 Paste resume content
* 🎯 Enter required job skills
* 📊 Calculate skill match percentage
* ✅ Display matched skills
* ⚡ Instant analysis
* 📱 Responsive and modern UI
* 🔒 Runs entirely in the browser

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## 🧠 How It Works

1. The user pastes their resume content.
2. The user enters job skills separated by commas.
3. The application checks which required skills are present in the resume.
4. It calculates the percentage of matched skills.
5. The result displays the match score and matched skills.
